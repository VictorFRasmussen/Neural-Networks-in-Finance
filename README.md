# Neural Networks in finance
A repository for doing work on the application of neural networks in financial problems. The repo consists of work done for two separate courses:
1. A paper written for the seminar: Advanced Finance (F) in Spring 2025. 
- The paper reviews two classic approaches to pricing american options: the Bjerksund-Stensland closed-form approximation and the Longstaff-Schwartz method. We then compare these methods to the modern Machine Learning technique of neural networks. We demonstrate that        NN's offer unmatched speed without negatively affecting accuracy.

2. A paper written for the course Dynamic Programming in Spring 2025.
- The paper looks at the problem of portfolio optimization with transaction costs. In the paper, we first solve the model using techniques from dynamic programming, and then analyze how this approached is hit by the curse of dimensionality. Inspired by the paper: A comprehensive machine learning framework for dynamic portfolio choice with transaction costs (Gaegauf, Scheidegger & Trojani), we investigate how machine learning, specifically neural nets, can be used to overcome the curse of dimensionality.
