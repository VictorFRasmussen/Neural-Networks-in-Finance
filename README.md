# Pricing American Options using Neural Networks
A paper written for the seminar: Advanced Finance (F) in Spring 2025. 
The paper reviews two classic approaches to pricing american options: the Bjerksund-Stensland closed-form approximation and the Longstaff-Schwartz method. We then compare these methods to the modern Machine Learning technique of neural networks. We demonstrate that NN's offer unmatched speed without negatively affecting accuracy.
